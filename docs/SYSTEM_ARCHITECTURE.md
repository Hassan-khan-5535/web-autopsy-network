# Web Autopsy Network — As-Built System Architecture

**Document Version:** 1.0 (Phase 15 Final Specification)  
**System:** Web Autopsy Network Distributed Digital Forensics Platform  

---

## 1. Overview & Core Design Philosophy

Web Autopsy Network is a distributed web intelligence and forensic analysis platform designed to dissect websites, collect observable telemetry, analyze security/performance bottlenecks, and produce evidence-grounded autopsy reports.

### Core Classification Taxonomy
Every single finding across all 10 analytical engines is categorized under a strict 4-level evidence taxonomy:

- 🟢 **OBSERVED**: Directly measured, immutable telemetry (HTTP headers, status codes, timing metrics, DOM nodes, cookies).
- 🟡 **INFERRED**: Technically derived conclusions computed deterministically from multiple observations (e.g., inferring bundle bloat from JS file sizes + parse delays).
- 🔵 **AI INTERPRETATION**: High-level diagnostic synthesis generated by an LLM strictly citation-grounded to valid observation/inference IDs.
- ⚫ **UNKNOWN**: Parameters that cannot be determined externally without invasive/unauthorized actions.

## 2. Distributed Architecture & Queue Topology

The platform uses FastAPI as an asynchronous gateway coordinator paired with Redis and Celery for distributed worker orchestration across four independently scalable queue pools:

```
                                [ User / Client ]
                                        │
                                        ▼
                            [ API Gateway / FastAPI ]
                                        │
                       ┌────────────────┴────────────────┐
                       │                                 │
                       ▼                                 ▼
             [ Redis Task Queue ]              [ PostgreSQL Storage ]
                       │                        (Indexed & Eager Loaded)
       ┌───────────────┼───────────────┬─────────────────┐
       ▼               ▼               ▼                 ▼
[ worker-crawl ] [ worker-browser ] [ worker-analysis ] [ worker-ai ]
(HTTP Crawl &    (Playwright        (Tech, Security,    (LLM Citation
 SSRF Guard)      Sandbox)           Perf Engines)       Gate & Summary)
```

### Worker Queue Specifications
1. `crawl` Pool (`worker-crawl`): I/O bound worker handling URL admission (SSRF validation), HTTP header extraction, and same-domain bounded crawling.
2. `browser` Pool (`worker-browser`): Isolated, sandboxed Playwright worker running headless Chromium inside an unprivileged, resource-constrained container (512MB RAM ceiling, 30s execution budget).
3. `analysis` Pool (`worker-analysis`): CPU-bound deterministic engines analyzing Technology DNA, Security headers, Performance metrics, WCAG Accessibility, and Content structure.
4. `ai` Pool (`worker-ai`): Constrained LLM worker processing AI Doctor Q&A and Executive Summaries behind strict citation validation gates.

## 3. Security Model & Defensive Safeguards

1. **Socket-Level SSRF Protection**: Inbound URL requests undergo host resolution and socket-level IP connection hooks (`validate_socket_ip`) blocking private IPv4/IPv6 ranges (RFC1918), loopback (`127.0.0.1`, `::1`), link-local (`fe80::`), and cloud metadata endpoints (`169.254.169.254`).
2. **DNS Rebinding & Redirect Defense**: Re-evaluates destination IP addresses on every HTTP redirect hop before opening connections.
3. **Browser Sandbox Isolation**: Chromium runs with `--no-sandbox`, `--disable-setuid-sandbox`, `--disable-local-file-access`, and a custom Playwright network interceptor aborting internal sub-resource requests.
4. **Prompt Injection Shield & Citation Gate**: Scraped HTML content is wrapped in `<untrusted_scanned_content>` XML tags. All LLM diagnostic output is verified against existing DB evidence IDs; ungrounded statements are automatically stripped or flagged as `[UNGROUNDED_CLAIM_REJECTED]`.
5. **Scan Wall-Clock Expiry**: Monitors active scan execution time; scans exceeding `SCAN_TIMEOUT_SECONDS = 600` transition cleanly to `PARTIAL_FAILED`.
